RAVISHKA NIMSARA — PORTFOLIO WEBSITE

Preview locally:
1. Extract this folder.
2. Open index.html in Chrome, Edge, or Firefox.

Publish on Netlify:
1. Go to https://app.netlify.com/drop
2. Sign in to Netlify.
3. Drag and drop the entire portfolio_site folder (or a ZIP of its contents) into the drop area.
4. Netlify will publish it and give you a public website URL.

Before publishing:
- In index.html, replace href="mailto:" on the contact button with href="mailto:YOUR_EMAIL@example.com".
- Optionally add Instagram, Behance, LinkedIn, or other professional links.
- The project previews use rendered pages from the supplied portfolio PDF, so the original page designs are preserved. For sharper individual project galleries, replace these page images with original design exports when available.

Everything is static HTML, CSS, and JavaScript. No framework or build step is required. Google Fonts are loaded online; system fallbacks are included.
